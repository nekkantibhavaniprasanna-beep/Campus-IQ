# Campus IQ 🎓

Campus IQ is a student-focused web application designed to help users stay updated with campus events, notifications, schedules, and important information in one place.

## Features

- 📅 Event Management
  - View upcoming campus events
  - Event details page
  - Event data stored in JSON format

- 🔔 Notifications
  - Important announcements and updates

- 🤖 Chatbot
  - Basic chatbot interface for student assistance

- 📆 Calendar
  - Track events and schedules

- 📄 Multiple Information Pages
  - About page
  - Event details page
  - Notifications page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
